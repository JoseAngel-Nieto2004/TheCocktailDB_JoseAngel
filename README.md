# TheCocktailDB App - Prueba Técnica

Este proyecto ha sido desarrollado como parte de una prueba técnica. La aplicación consume la API pública de TheCocktailDB y muestra información detallada de las bebidas disponibles.

## Tecnologías utilizadas

- Angular - 19.2.11
- npm - 11.3.0
- node - 22.11.0
- Tailwind CSS
- TheCocktailDB API
- TypeScript
- HTML / CSS

## Instalación y ejecución

Para clonar el repositorio, instalar todas las dependencias necesarias (incluyendo Tailwind CSS), compilar el proyecto y levantar el servidor local, puedes usar:

```bash
npm run setup
```
Este comando ejecuta:

- Instalación de dependencias (npm install)
- Instalación de TailwindCSS y sus plugins (postcss, autoprefixer)
- Compilación del proyecto (ng build)
- Servidor de desarrollo (ng serve)

También puedes ejecutar cada paso manualmente:

```bash
Copiar
Editar
npm install
npm install tailwindcss @tailwindcss/postcss postcss --force
ng build
ng serve
```
